# Publishing the Industrial Atlas

## The recruiter-facing package

Use three surfaces, each with one job:

1. **Personal website:** earns the click with the investment question and three proof points.
2. **Live Atlas:** proves the research and product are real within 60–90 seconds.
3. **GitHub:** proves ownership, methodology, data discipline and technical execution.

Do not send a recruiter to a file tree first. The primary link on a résumé should be the live Atlas or the project case study on the personal site.

## GitHub setup

- Create a dedicated public repository named `industrial-atlas` from this folder.
- Use the description: `Fundamental industrial research tracing macro and physical signals into company earnings, valuation and investment decisions.`
- Add topics: `fundamental-research`, `equity-research`, `commodities`, `supply-chain`, `data-visualization`, `react`, `sqlite`.
- Pin the repository on the profile.
- Upload `docs/industrial-atlas-social-card.svg` as the basis for a 1280 × 640 PNG social preview in repository settings.
- Keep the recruiter-oriented README at the root.
- Add the live URL to the repository website field.
- Use tagged releases for portfolio milestones rather than presenting every intermediate commit as finished research.

## Personal website setup

- Paste `docs/personal-site-project.html` into the projects or featured-work section.
- Replace both placeholder URLs with the live Atlas and GitHub repository.
- Place Industrial Atlas in the first or second project position.
- Use the headline `From physical supply-chain change to an investable conclusion`.
- Link the project image and the `Explore the live Atlas` button to the same live entry point.
- Add one résumé bullet beside it: `Built an industrial-research platform connecting macro, commodity and primary-research signals to company forecasts, valuation and explicit investment decisions.`

## Recommended 90-second journey

1. Read the homepage thesis and select **Open BYD**.
2. Inspect the conclusion, variant view, forecast and valuation logic.
3. Return to the homepage and open **China EAF** to see primary research converted into monitorable indicators.
4. Open the **nickel hierarchy** to see how the same process scales across a physical industrial system.

## Pre-publication checks

- Every prominent number has a date, unit and source or is clearly labelled as an estimate.
- Forecasts are visibly separated from reported data.
- Illustrative relationships are not presented as documented contracts.
- The live site opens without local setup and works at common laptop and mobile widths.
- No private interviewee names, confidential notes, API keys or licensed datasets are committed.
- The homepage does not describe unfinished examples as complete.
- The README, live URL, social preview and personal-site links all agree on the same one-line pitch.

## What success looks like

The recruiter should understand in under 30 seconds that this is not another market-data dashboard. It is evidence of an analyst workflow: identify a variant question, assemble the physical and financial evidence, translate it into estimates, value the outcome, and state what would change the decision.
